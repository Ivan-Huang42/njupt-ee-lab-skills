# 预习报告内容模板

## 一、预习目的

写 3～4 条，动词开头，和本次实验的操作/测量对应。

示例：

1. 理解 KCL、KVL 的表述与参考方向约定。
2. 掌握用叠加定理分析双电源电路的方法。
3. 掌握戴维南等效参数的测量与计算。
4. 用仿真预测实验结果，为实测提供对照。

避免：

- “了解电工电子实验的基本知识”
- “培养动手能力”
- 与本次实验无关的套话

## 二、预习原理

每个定理按三部分写：

1. **陈述**：一句话说清定理内容。
2. **公式**：单独成行，变量与单位写全。
3. **条件**：适用前提、参考方向、不能用于什么。

示例：

```text
叠加定理：在线性电路中，多个独立源共同作用时，任一支路响应等于各独立源单独作用时响应之代数和。
I = I′ + I″
只适用于线性电路；每次只保留一个独立源，其余电压源短路、电流源开路；功率不能叠加。
```

## 三、实验电路与参数

- 先用一段话说明拓扑：电源从哪里接入、节点如何编号、以哪个节点为地。
- 规定参考方向：电流从哪个节点流向哪个节点为正。
- 元件参数用表列出，单位写在表头。
- 有电路图时插入 `figure` 块；图题在图下。

参数表例：

```json
{
  "type": "table",
  "caption": "表 1  电阻参数",
  "shade": true,
  "rows": [
    ["元件", "R1", "R2", "R3", "R4", "R5"],
    ["阻值 / Ω", "200", "200", "100", "220", "100"]
  ]
}
```

## 四、理论计算与仿真预测

- 先写计算思路：选了哪些节点、哪些回路、列了几个方程。
- 再给结果表：理论值、仿真值、相对偏差。
- 仿真值必须来自 `circuit-simulation` 或等效工具，不能凭空写。
- 相对偏差：`|仿真 − 理论| / 理论 × 100%`，保留 1～2 位有效数字。

对照表例：

```json
{
  "type": "table",
  "caption": "表 2  理论值与仿真值对照",
  "shade": true,
  "rows": [
    ["物理量", "理论值", "仿真值", "相对偏差"],
    ["UAB / V", "1.047", "1.047", "0.0%"],
    ["IR1 / mA", "5.235", "5.235", "0.0%"]
  ]
}
```

## 五、预习结论

写 3 条以内，回答：

1. 预判电路会呈现什么行为？
2. 哪个定理/公式是本次实验的关键？
3. 实验中需要重点验证哪两个量？

## 六、注意事项

从下面几类里选 4～6 条，结合本次实验写具体：

- 断电接线、电源极性、共地。
- 电流表串联、电压表并联、量程选择。
- 参考方向与负号。
- 元件发热、限流电阻。
- 开路/短路测量的操作细节。
- 思考题预答（先写题号）。

## 篇幅控制

| 章节 | 建议页数 |
|---|---|
| 封面 | 1 页（可选） |
| 一、预习目的 | 0.2 页 |
| 二、预习原理 | 0.5～1 页 |
| 三、实验电路与参数 | 0.3～0.6 页 |
| 四、理论计算与仿真预测 | 0.6～1 页 |
| 五、预习结论 | 0.2 页 |
| 六、注意事项 | 0.3～0.5 页 |

总计 3～4 页；手写版通常控制在 3 页内，见 `handwritten-preview`。
