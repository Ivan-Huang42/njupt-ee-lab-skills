# 预习报告内容撰写

## 适用范围

- 实验前预习：读讲义、列原理、算参数、给仿真预测、写注意事项。
- 生成可打印的 A4 预习报告 docx；需要“手写版”时改用 `handwritten-preview`。
- 不用于实验后的正式报告；正式报告用 `lab-report`。
- 不编造仿真或实测数据：仿真值来自 `circuit-simulation`，理论值必须给出计算过程。

## 输入清单

1. 本次实验名称与讲义页码。
2. 实验目的、仪器、电路图或拓扑描述。
3. 元件参数（电阻、电源、二极管型号等）。
4. 需要预习的定理/公式（基尔霍夫、叠加、戴维南、诺顿、分压分流等）。
5. 讲义中的思考题。
6. 学校/学院/班级/学号/姓名/指导教师/学期。
7. 是否需要封面与页眉；不需要时在配置中设 `"cover": false`。
8. 封面校徽：把 `logo.png` 放在配置文件同目录，或设置 `meta.logo`；没有校徽时封面自动留白。

## 工作流程

1. **读讲义**：标出本次实验要验证的定理、必测物理量、思考题。
2. **列原理**：每个定理用“陈述 + 公式 + 适用条件”三句话写清，不抄整页教材。
3. **定参数**：把电路元件值整理成表；标出参考方向与节点。
4. **做预测**：先用理论公式手算，再用 `circuit-simulation` 仿真；两者不一致时先查单位和参考方向。
5. **写内容**：按 `references/content.md` 的六段结构写 `blocks`。
6. **生成 docx**：`node scripts/build_preview.js 配置.json`。
7. **检查**：表格不跨页、公式符号正确、仿真值与理论值能对上。
8. **交付**：命名 `学号-姓名-第x次预习报告.docx`，按老师要求转 PDF。

## 内容结构

| 章节 | 写什么 | 篇幅 |
|---|---|---|
| 一、预习目的 | 本次要掌握/验证什么 | 3～4 条 |
| 二、预习原理 | 定理陈述、公式、适用条件 | 半页到一页 |
| 三、实验电路与参数 | 拓扑说明、元件表、参考方向 | 半页 |
| 四、仿真预测 | 理论值、仿真值、偏差 | 一张到两张表 |
| 五、预习结论 | 预判电路行为、待验证点 | 3 条以内 |
| 六、注意事项 | 接线、量程、易错点、思考题预答 | 半页 |

## 写作要求

- 原理只写本次要用的，不铺陈教材背景。
- 公式单独成行、居中；变量与单位写全。
- 数据表第一列为自变量，单位写在表头，如 `U / V`。
- 仿真值注明“仿真值”，理论值注明“理论值”，不要混写。
- 结论要能对应预习目的，不写“通过本次预习学到了很多”这类空话。
- 思考题先写题号，再写答案；没把握的标注“待实验验证”。

## 快速开始

```powershell
cd <本技能目录>\scripts
npm install docx
node build_preview.js preview.example.json
```

输出文件名由配置中的 `out` 决定，相对路径以配置文件所在目录为基准。

## 配置格式

与 `lab-report` 相同，使用 `blocks` 描述正文：

```json
{
  "out": "B00000000-张三-第一次预习报告.docx",
  "headerText": "电工电子实验教学中心",
  "meta": {
    "reportTitle": "电工电子实验预习报告",
    "course": "电工电子实验（一）",
    "title": "基尔霍夫定律、叠加定理与戴维南定理",
    "college": "通信与信息工程学院",
    "class": "你的班级",
    "sid": "你的学号",
    "name": "你的姓名",
    "teacher": "指导教师",
    "term": "2026—2027 学年  第一学期"
  },
  "bodyTitle": "实验名称：基尔霍夫定律、叠加定理与戴维南定理",
  "blocks": [
    { "type": "h1", "text": "一、预习目的" },
    { "type": "p", "text": "..." },
    { "type": "table", "caption": "表 1  电阻参数", "rows": [["元件", "阻值"], ["R1", "200 Ω"]] }
  ]
}
```

支持的块类型：`h1`、`h2`、`p`、`note`、`formula`、`pagebreak`、`figure`、`table`。

- `figure`：`{"type":"figure","file":"图1.png","width":520,"height":289,"caption":"图 1  ..."}`，图片路径相对配置文件。
- `table`：`{"caption":"表 1  ...","rows":[...],"shade":false,"widths":[...]}`。
- `"cover": false` 可去掉封面；此时页眉从第一页开始。

## 常见错误

- 把正式报告的“实验数据/结果分析”照搬进预习报告：预习阶段只能写预测。
- 仿真值没有注明来源，和理论值混在一列。
- 参考方向没标，叠加定理出现符号错误。
- 表格跨页断头：拆表或减少行数。
- 封面写了上次实验的名称。
- 公式用截图：必须用文字或 Word 公式。

## 工具链

- `scripts/build_preview.js`：配置驱动生成 docx。
- `scripts/preview.example.json`：完整示例。
- `references/content.md`：六段结构模板与句式。
- `circuit-simulation`：生成预习所需的仿真值。
