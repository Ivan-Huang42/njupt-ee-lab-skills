# 正式实验报告格式与检查表

## 一、封面

依次为：

```
南京邮电大学校徽
电工电子实验报告
课程名称：电工电子实验（一）
实验名称：<本次实验名称>
学　　院：<学院名称>
班　　级：<班级>
学　　号：<学号>
姓　　名：<姓名>
指导教师：<教师姓名>
学　　期：<学年  学期>
```

- 校徽从官方模板或格式详解文档中提取，不要用截图。
- 封面页不显示页眉。

## 二、正文结构

### 1. 实验目的

3～4 条，动词开头，说明通过本次实验要掌握什么、验证什么。

### 2. 实验仪器

列出名称、型号、数量。例如：直流稳压电源、数字万用表、面包板、电阻、二极管。

### 3. 实验原理

- 验证性实验控制在 150 字以内，写清公式和判据。
- 设计性实验可适当展开，但不超过半页。
- 公式用 Word 公式编辑器或纯文本，变量斜体可选。

### 4. 测试电路

- 每个测量项目一张图，图号连续。
- 标出电源、限流电阻、电流表、电压表、被测元件、节点。
- 图题格式：`图 1  线性电阻测量电路`。

### 5. 实验数据

- 一张表对应一组测量，表号连续。
- 表题在表上方：`表 1  线性电阻伏安特性`。
- 第一列为自变量，单位写在表头，如 `Ur / V`。
- 有效数字统一：电压 0.01 V，电流 0.01 mA（按仪表分辨率）。

### 6. 特性曲线

- 曲线用实测数据绘制，不用截图。
- 坐标轴必须有物理量名称和单位。
- 正反向画在同一张图时，反向电流若为 μA 级，需在图中注明单位或比例。
- 图题在图下方。

### 7. 结果分析

回答三个问题：

1. 数据是否符合理论趋势？
2. 关键参数是多少（R、Ud、Uz 等）？
3. 偏差来源是什么（仪表内阻、读数误差、元件公差）？

### 8. 结论

3 条以内，对应实验目的，用数据支撑。

### 9. 实验小结

写操作体会、易错点、改进建议，不超过 200 字。

### 10. 思考题

按讲义题目逐条作答，先写题号再写答案。

### 11. 附录

仿真电路、原始数据、波形截图（若是自己仿真的结果）。

## 三、图表规范

| 项目 | 要求 |
|---|---|
| 图号 | 图 1、图 2……全文连续 |
| 表号 | 表 1、表 2……全文连续 |
| 图题位置 | 图下方，居中，五号宋体 |
| 表题位置 | 表上方，居中，五号宋体 |
| 图宽 | 单栏 10～12 cm，并排两张各 7.5 cm |
| 图片格式 | PNG 300 dpi 或 SVG |
| 表格边框 | 全框线，线宽 0.5～0.75 pt |
| 表头 | 可浅灰，不加粗也可 |
| 跨页 | 尽量不跨页；必须跨页时重复表头 |

## 四、数据与误差

- 原始数据先记录，再整理；不要先画曲线再倒推数据。
- 异常点判断顺序：接线错误 → 量程错误 → 读数错误 → 元件发热 → 仪表误差。
- 允许在仪表分辨率范围内修正明显笔误，但必须保持物理趋势。
- 相对误差：`|实测 − 理论| / 理论 × 100%`，保留 1～2 位有效数字。

## 五、命名与提交

- 报告：`学号-姓名-SYx-BGx.pdf`，例如 `B00000000-张三-SY1-BG1.pdf`。
- 预习：按老师当次要求命名；无要求时用 `学号-姓名-第x次预习报告`。
- 提交前确认：PDF 能打开、页数正确、图表清晰、姓名学号无误。

## 六、提交前检查表

- [ ] 封面实验名称与本次实验一致
- [ ] 指导教师姓名正确
- [ ] 页眉只出现在正文页
- [ ] 每个测量项目都有电路图
- [ ] 图号、表号连续，无跳号
- [ ] 图题在图下、表题在表上
- [ ] 图与图题没有被分页隔开
- [ ] 表格没有跨页断头
- [ ] 坐标轴有物理量和单位
- [ ] 数据有效数字统一
- [ ] 结果分析引用了具体数据
- [ ] 结论对应实验目的
- [ ] 思考题全部作答
- [ ] 文件命名“学号-姓名-SYx-BGx”
- [ ] 已导出 PDF 并逐页检查
