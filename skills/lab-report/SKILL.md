# 电工电子实验报告生成

## 适用范围

- 按南京邮电大学电工电子实验中心格式，产出正式实验报告（docx，可转 PDF）。
- 其他学校可修改封面字段、页眉文字与 `references/format.md` 后复用。
- 有实测数据、讲义报告要求，需要插入电路图、特性曲线、数据表。
- 不用于预习报告；预习报告见 `preview-report` 与 `handwritten-preview`。

## 输入清单

开始前必须确认：

1. 讲义中的报告要求：验证性还是设计性、必填图表、思考题。
2. 实测数据（原始记录，含单位）。
3. 实验名称、项目编号 `SYx`、报告编号 `BGx`。
4. 指导教师姓名。
5. 报告提交格式（docx / PDF）。
6. 封面校徽：把 `logo.png` 放在配置文件同目录，或在 `meta.logo` 中指定路径；没有校徽时封面自动留白。

## 工作流程

1. **读讲义**：确认报告结构、必填项、图表数量；不要套用上一次实验的模板。
2. **数据体检**：检查量级、单位、单调性、重复点；异常点只在仪器误差范围内修正，禁止编造数据。
3. **画图**：电路图用 schemdraw、Visio、EDA 工具重绘，或手绘后拍照，禁止截图教材或网页；曲线根据数据绘制。
4. **写配置**：复制 `scripts/report.example.json`，填写 `meta` 与 `blocks`。
5. **生成 docx**：运行 `node scripts/build_report.js 配置.json`。
6. **导出 PDF**：用 WPS/Word 导出，逐页渲染检查分页、图题、表格。
7. **命名**：`学号-姓名-SYx-BGx.pdf`，学号在前、姓名在后。
8. **自检**：按 `references/format.md` 的检查表逐项确认。

## 格式硬指标

| 项目 | 要求 |
|---|---|
| 页面 | A4，上下 2 cm，左右 2.54 cm |
| 正文 | 宋体 / Times New Roman，小四（12 pt），1.5 倍行距 |
| 一级标题 | 黑体四号（14 pt），加粗 |
| 二级标题 | 黑体小四（12 pt），加粗 |
| 图题、表题 | 宋体五号（10.5 pt），居中；图题在图下，表题在表上 |
| 表格 | 全框线，表头可用浅灰；字号五号 |
| 页眉 | “电工电子实验教学中心”，带下划线，封面不显示 |
| 封面 | 校徽 + 课程/实验/学院/班级/学号/姓名/指导教师/学期 |

## 报告结构

按讲义要求组织，通常包含 11 项：

1. 实验目的
2. 实验仪器
3. 实验原理
4. 测试电路
5. 实验数据
6. 特性曲线
7. 结果分析
8. 结论
9. 实验小结
10. 思考题
11. 附录（仿真、原始数据）

## 常见错误

- 图与图题被分页隔开：图片段落必须 `keepNext`。
- 表格跨页后没有表头：拆成两张表，或设置重复表头。
- 电压表接法错误：外接法跨被测元件，内接法跨“电流表 + 元件”。
- 命名写成“姓名-学号”：正确是“学号-姓名-SYx-BGx”。
- 单位缺失或有效数字不统一：同一物理量保留相同小数位。
- 直接截图教材、网页：报告明确禁止，必须重新绘制。
- 用上一次报告的封面和页眉：实验名称、编号要同步修改。

## 工具链

- `scripts/build_report.js`：读取 JSON 配置生成 docx。
- `scripts/report.example.json`：配置示例。
- `references/format.md`：详细格式、结构模板、检查表。
- 电路图：schemdraw、Visio、EDA 工具重绘，或手绘后拍照（禁止截图）。
- PDF 检查：导出后渲染成图片逐页查看。

## 运行环境

```powershell
cd <本技能目录>\scripts
npm install docx
node build_report.js report.json
```

首次使用安装一次 `docx` 即可。
