# 预习报告手写版

## 适用范围

- 把预习报告内容排成“可直接照抄到信纸”的手写稿。
- 默认适配南京邮电大学信纸可写区域：158 mm × 217 mm。
- 其他信纸/纸张可修改配置里的 `page` 与 `line`。
- 不用于正式实验报告；正式报告用 `lab-report`。

## 默认版式

| 项目 | 默认值 | 说明 |
|---|---|---|
| 页面 | 158 mm × 217 mm | 8957 × 12302 twips |
| 页边距 | 0 | 四边全部为 0 |
| 字体 | 平方相思体 | 配置 `font` 可改，建议 `KaiTi` 作后备 |
| 正文字号 | 12 pt | 与手写习惯接近 |
| 行距 | 20.5 pt 固定值 | 每页约 30 行 |
| 表格字号 | 9 pt | 表格只保留黑色框线 |
| 图表题 | 10.5 pt | 图题在下、表题在上 |
| 加粗 | 禁止 | 全文不加粗 |
| 填色 | 禁止 | 表头不填色 |
| 页眉页脚 | 无 | 不插页码 |

## 输入清单

1. 预习报告正文（可先用 `preview-report` 起草）。
2. 是否需要标题；标题默认 20 pt 居中。
3. 图表文件（可选），路径相对配置文件。
4. 需要强制分页的位置。
5. 本机是否安装手写字体。

## 工作流程

1. **定内容**：先完成 `preview-report` 的六段内容，删到 3 页以内。
2. **写配置**：复制 `scripts/hand.example.json`，填写 `title` 与 `blocks`。
3. **生成 docx**：`node scripts/build_hand.js 配置.json`。
4. **转 PDF**：用 Word/WPS 导出，检查页数与分页。
5. **逐页检查**：表题是否和表格同页、图题是否和图同页、是否有孤行。
6. **照抄**：按 PDF 的行位置抄到信纸上；不需要打印手写体。

## 快速开始

```powershell
cd <本技能目录>\scripts
npm install docx
node build_hand.js hand.example.json
```

## 配置格式

```json
{
  "out": "B00000000-张三-第二次预习报告-手写版.docx",
  "title": "第二次预习报告",
  "font": "平方相思体",
  "page": { "width": 8957, "height": 12302 },
  "blocks": [
    { "type": "h1", "text": "一、预习目的" },
    { "type": "p", "text": "..." },
    { "type": "table", "caption": "表 1  电阻参数", "rows": [["元件", "R1"], ["阻值 / Ω", "200"]] },
    { "type": "pagebreak" }
  ]
}
```

可选字段：

- `font`：字体名，默认 `平方相思体`。
- `page.width` / `page.height`：页面尺寸（twips）。
- `line`：固定行距（twips），默认 `410`。
- `bodySize` / `smallSize` / `captionSize` / `titleSize`：字号（半磅），默认 24 / 18 / 21 / 40。
- `blocks[].pageBreak`：在 `h1` 上设置 `true`，该节从新页开始。

支持的块类型：`h1`、`h2`、`p`、`note`、`formula`、`pagebreak`、`figure`、`table`。

## 字体安装

1. 下载/准备 `平方相思体.ttf`（或学校常用手写体）。
2. Windows：右键字体文件 →“安装”；或复制到 `%LOCALAPPDATA%\Microsoft\Windows\Fonts`。
3. 没安装时 Word 会自动替换字体，排版会变，必须先装字体再生成 PDF。
4. 没有该字体时，把 `font` 改为 `KaiTi`（楷体）也能得到接近手写的效果。

## 排版规则

- 正文首行缩进 2 字符；`note`、`formula` 不缩进。
- 所有段落使用固定行距，保证每页行数一致。
- 标题与正文同字号，只用“一、二、三”区分层级，模拟手写稿。
- 表格只保留黑色单线框，表头不加粗、不填色。
- 表格行设置 `cantSplit`，避免一行被拆到两页。
- 表题在表上、图题在图下，均设置 `keepNext`。
- 图与图题、表题与表格不能被分页隔开。
- 需要换页时显式插入 `pagebreak`，不要靠空行顶。

## 常见错误

- **字体没装**：PDF 里变成宋体，行宽变化，照抄时对不上。
- **用了加粗/填色**：打印或照抄时出现“特效”，不符合手写稿要求。
- **行距用了倍数**：每页行数会漂移，改用固定值 20.5 pt。
- **页边距不是 0**：内容区小于 158×217 mm。
- **表格跨页**：拆表或在表前分页。
- **图题单独留在页尾**：给图片段落和表题设置 `keepNext`。
- **直接打印到信纸**：普通打印机有不可打印边距，先导出 PDF 检查，再决定是否打印。

## 工具链

- `scripts/build_hand.js`：配置驱动生成手写版 docx。
- `scripts/hand.example.json`：两页示例（内容偏短时会自然排成两页）。
- `references/format.md`：版式参数、检查表、常见纸张换算。
- `preview-report`：先写内容，再排手写版。
