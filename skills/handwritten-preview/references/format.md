# 手写版版式说明

## 一、页面参数

| 项目 | 数值 | 换算 |
|---|---|---|
| 可写宽度 | 158 mm | 8957 twips |
| 可写高度 | 217 mm | 12302 twips |
| 页边距 | 0 | 上下左右全 0 |
| 行距 | 20.5 pt | 410 twips，固定值 |
| 每页行数 | 约 30 行 | 217 mm ÷ 20.5 pt |
| 正文字号 | 12 pt | 24 半磅 |
| 表格字号 | 9 pt | 18 半磅 |
| 图表题 | 10.5 pt | 21 半磅 |
| 标题 | 20 pt | 40 半磅 |

换算公式：

```text
twips = mm × 1440 ÷ 25.4
158 mm → 8957 twips
217 mm → 12302 twips
```

其他纸张按同样公式改 `page.width` / `page.height`。

## 二、字体

- 默认：`平方相思体`。
- 后备：`KaiTi`（楷体）、`STKaiti`（华文楷体）。
- 必须在本机安装字体后再导出 PDF，否则 Word 会替换字体，行宽和分页都会变。
- 不要在同一份手写稿里混用多种字体。

## 三、排版规则

1. 全文不加粗、不倾斜、不加下划线。
2. 表格只有黑色单线框，表头不填色、不加粗。
3. 标题与正文同字号，用“一、二、三”区分层级。
4. 正文首行缩进 2 字符；`note`、`formula` 不缩进。
5. 公式单独成行、居中。
6. 图题在图下，表题在表上，均为 10.5 pt。
7. 图与图题、表题与表格必须同页。
8. 表格行不跨页；表格尽量整体放在一页。
9. 需要换页时显式插入 `pagebreak`。
10. 不插页眉、页脚、页码。

## 四、内容长度控制

| 内容 | 建议行数 |
|---|---|
| 标题 | 1 行 |
| 预习目的 | 4～6 行 |
| 预习原理 | 12～16 行 |
| 电路与参数 | 6～8 行 + 两张小表 |
| 理论/仿真预测 | 8～10 行 + 两张表 |
| 预习结论 | 3～4 行 |
| 注意事项 | 4～6 行 |

两到三页共约 60～90 行；超过 90 行时优先删原理背景和重复表述。

## 五、分页检查

导出 PDF 后逐页检查：

- [ ] 页面是 158 × 217 mm，不是 A4
- [ ] 四边没有页边距
- [ ] 字体是手写体，不是宋体
- [ ] 每页约 30 行，行距一致
- [ ] 没有加粗、填色、下划线
- [ ] 表格框线为黑色单线
- [ ] 表题与表格同页
- [ ] 图题与图片同页
- [ ] 没有半行孤字留在页尾
- [ ] 总页数在老师要求范围内

## 六、打印与照抄

- 普通打印机有 3～5 mm 不可打印边距，零页边距文档直接打印可能被裁切。
- 推荐流程：导出 PDF → 在阅读器里按“实际大小”查看 → 照抄到信纸。
- 若必须套打，先用一张废纸试打，确认行列位置与信纸横线对齐。
- 手写时按 PDF 的换行位置抄，不要自行压缩行距。
